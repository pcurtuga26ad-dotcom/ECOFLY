Ayuda

Preguntas frecuentes

¿Qué modelo debería elegir?

Agrimax 30L y HydroSpray 20L están planteados para pulverización; AgroScan Pro, para inspección; MicroSpray Compact, para espacios reducidos. Confirma las necesidades técnicas antes de elegir un equipo real.

¿Los accesorios son compatibles con todos los drones?

No. La compatibilidad mostrada en este proyecto es propuesta y debe validarse con la ficha del fabricante antes de comprar.

¿Qué incluye el mantenimiento preventivo?

La propuesta incluye revisión de componentes, baterías y recomendaciones de cuidado. El alcance real debe confirmarse en un presupuesto.

¿Las garantías y precios son reales?

No. Son importes y condiciones ficticios para una demostración académica.

¿Cómo se gestionan las baterías usadas?

Debe utilizarse un canal adecuado de recogida o reciclaje según la batería y las normas locales. No deseches baterías con residuos domésticos.

¿Qué requisitos legales se aplican al uso de drones?

El uso debe cumplir la normativa vigente, las instrucciones del fabricante y los requisitos aplicables a la operación, el equipo y el lugar. Comprueba las condiciones oficiales antes de volar.

¿Cómo funcionan los envíos y las devoluciones?

Esta web es una demostración sin logística real. Las condiciones deben definirse antes de una publicación comercial.

¿Puedo pagar en la web?

Solo se puede simular el proceso de compra. No introduzcas datos bancarios reales; no hay una pasarela de pago conectada.
