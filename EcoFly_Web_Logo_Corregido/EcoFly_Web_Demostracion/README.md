# EcoFly — web demostrativa

## Cómo abrirla
1. Descomprime el archivo ZIP.
2. Abre `index.html` con Chrome, Edge o Firefox. No necesita instalar dependencias ni servidor.

## Incluye
- Navegación por secciones, cuatro drones y fichas técnicas demostrativas.
- Comparativa de modelos, catálogo de accesorios, filtros y buscador.
- Los 50 registros de packs solicitados.
- Servicios, sostenibilidad, sobre nosotros, FAQ, contacto y páginas legales provisionales.
- Carrito con cantidades, subtotal, código DEMO5 e IVA demostrativo del 21 %.
- Checkout simulado sin cobro, cuenta simulada y seguimiento de pedidos de ejemplo.
- Fichas imprimibles: abre la ficha de un dron y pulsa «Imprimir / guardar PDF», después elige «Guardar como PDF».

## Limitaciones
Esta es una web estática local. No tiene backend, base de datos, pasarela de pago, autenticación real, envío de formularios ni integración logística. No introduzcas datos bancarios reales. Los precios, especificaciones, garantías, compatibilidades, inventario y pedidos son ficticios. Las imágenes de producto son ilustraciones vectoriales conceptuales integradas en la web, no fotografías de hardware real. Los datos empresariales y textos legales deben completarse y revisarse antes de publicar.
